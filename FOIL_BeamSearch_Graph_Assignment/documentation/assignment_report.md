## 3. Introduction

The graph path problem is suitable for this assignment because it can be represented naturally using logical facts. Direct connections are represented by `edge(X,Y)`, and reachable nodes are represented by `path(X,Y)`. A recursive rule is also needed because a path may contain more than one edge.

## 6. FOIL Algorithm

FOIL means First Order Inductive Learner. It learns first-order logic rules from positive and negative examples. It starts with a very general rule and adds literals one by one.

Initial rule:

```prolog
path(X,Y) :- true.
```

Simple pseudocode:

```text
Start with an empty rule body
While the rule still covers negative examples:
    Generate candidate literals
    Calculate FOIL Gain for each literal
    Select the literal with the highest gain
    Add the selected literal to the rule
Remove positive examples covered by the rule
Repeat if positive examples remain
```

Candidate literals include:

```prolog
edge(X,Y)
edge(X,Z)
edge(Z,Y)
path(Z,Y)
```

## 7. FOIL Gain

FOIL Gain is used to select the best literal.

```text
Gain(L, R) = t × [ log2(p1 / (p1 + n1)) - log2(p0 / (p0 + n0)) ]
```

Here:

- `p0` = positive examples before adding literal
- `n0` = negative examples before adding literal
- `p1` = positive examples after adding literal
- `n1` = negative examples after adding literal
- `t` = number of positive examples still covered

A useful literal keeps positive examples covered and removes negative examples.

## 8. Beam Search Algorithm

Beam Search is a General-to-Specific search method. It starts with the most general rule and creates more specific candidate rules by adding literals.

In this assignment:

- Beam width `k = 3`
- Candidate rules are generated by adding literals
- Each candidate is scored using accuracy and coverage
- The best 3 rules are kept at each level

Beam Search is less greedy than FOIL because it keeps more than one candidate rule during the search.

## 10. Python Implementation Explanation

The dataset is stored manually in `data/graph_dataset.py`. The program loads the nodes, edges, and positive path examples. It then creates negative examples from all ordered node pairs that are not positive paths.

In FOIL, the learner starts with `path(X,Y) :- true.` and tests candidate literals. It first learns the direct edge rule:

```prolog
path(X,Y) :- edge(X,Y).
```

After removing the positive examples covered by the direct rule, it learns the recursive rule:

```prolog
path(X,Y) :- edge(X,Z), path(Z,Y).
```

In Beam Search, candidate rules are generated by adding literals. The best 3 candidates are kept at each level. The same two final rules are selected.
